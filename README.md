# Tabletop Chess

A simple, beautifully designed chess game built specifically for a tabletop form factor. Designed for large touchscreen tables where players are physically seated opposite each other.

## Features
- **Tabletop Native**: UI and controls are designed for two players sitting across from each other (180-degree flipped controls for the opponent).
- **Zero Setup**: A purely client-side application. Just open the web app and start playing.
- **Offline Capable**: Built as a Progressive Web App (PWA) so it can be installed on devices and played anywhere without an internet connection.
- **Modern Tech Stack**: Powered by SvelteKit (Svelte 5) and rigorously tested with Playwright.
